# 수학교육론 임용 대비 웹앱

중등 수학 임용을 준비하는 예비교사를 위한 수학교육론 서답형 학습 웹앱입니다.

- **개념학습 273문항**: 『수학교육신론』(황혜정 외, 2023)과 『수학교육과정과 교재연구』(김남희 외, 2024)의 모든 소단원별 문항입니다.
  - 설명하기 문항: 예) "오수벨의 점진적 분화의 원리를 설명하시오."
  - 용어 쓰기 문항: 설명을 읽고 해당 용어를 씁니다.
  - 기출에 자주 나오지만 두 교재 목차에 없는 이론은 "기출 빈출 보충"에 따로 모았습니다(브루너, 딘즈, 피아제, 비고츠키, 수리철학, 교육과정 역량·평가 등).
- **기출문제 69문항**: 2016~2026학년도 중등 1차 전공 A·B의 수학교육론 문항입니다(매년 24점).
  - 문항 원문 이미지를 보고 제한 시간 안에 답안을 작성합니다.
  - 이론별·연도별로 볼 수 있고, 묶음 전체를 세트로 이어서 풀 수도 있습니다.
- **채점과 기록**: 필수 키워드(동의어 포함)를 기준으로 채점하고 모범답안·해설을 보여 줍니다. 학번·이름과 함께 구글 시트에 기록합니다.

> 키워드 채점은 핵심 용어가 들어 있는지만 확인하는 참고용 채점입니다. 논리가 맞는지는 모범답안과 비교해 스스로 점검하도록 안내하고 있습니다.

## 폴더 구성

```
index.html          웹앱 본체 (단일 페이지)
config.js           구글 앱스 스크립트 URL 설정
data/concepts.js    개념학습 문항·키워드·모범답안
data/exams.js       기출 문항 정보·채점 요소·모범답안·해설
img/                기출 문항 원문 이미지 (평가원 PDF에서 문항별로 잘라냄)
Code.gs             구글 앱스 스크립트 코드 (시트 기록용, 깃허브에 올려도 무방)
netlify.toml        넷리파이 배포 설정
```

## 1단계: 구글 시트와 앱스 스크립트

1. 구글 드라이브에서 새 스프레드시트를 만듭니다. 이름은 예를 들어 "수학교육론 학습 기록"으로 합니다.
2. 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 `Code.gs` 내용을 지우고, 이 폴더의 `Code.gs` 내용을 붙여 넣은 뒤 저장합니다.
4. 위쪽 함수 선택에서 **`setup`**을 고르고 **실행**합니다. 권한 승인 창이 뜨면 허용합니다.
   - 실행이 끝나면 시트에 `기록` 탭과 `학생별 요약` 탭이 생깁니다.
5. **배포 → 새 배포**를 누릅니다.
   - 유형 선택(톱니바퀴): **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
6. **배포**를 누르고, 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

> Code.gs를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영됩니다. 이렇게 하면 URL은 그대로 유지됩니다.

### 시트에 기록되는 항목

제출 시각, 학번, 이름, 모드(개념학습/기출문제), 문항 ID, 구분, 단원/이론, 문항, 제출 답안, 점수, 만점, 득점률(%), 포함 키워드, 누락 키워드, 소요 시간(초), 제한 시간(초), 시간 초과

- `학생별 요약` 탭은 학번·이름·모드별 제출 수와 평균 득점률을 자동으로 집계합니다.

## 2단계: config.js 설정

`config.js`의 `GAS_URL`에 1단계에서 복사한 주소를 붙여 넣습니다.

```js
window.APP_CONFIG = {
  GAS_URL: "https://script.google.com/macros/s/여기에_복사한_ID/exec",
  APP_TITLE: "수학교육론 임용 대비",
  PASS_RATE: 70
};
```

`PASS_RATE`는 개념학습의 복습 기준입니다. 이 값 미만이면 해당 문항이 복습 목록에 담깁니다.

## 3단계: 깃허브에 올리기

1. 깃허브에서 새 저장소를 만듭니다. 예: `math-edu-imyong`
2. 이 폴더 안의 파일 전체를 저장소 최상위에 올립니다. 웹에서 **Add file → Upload files**로 폴더째 끌어다 놓아도 됩니다.

## 4단계: 넷리파이 배포

1. 넷리파이에서 **Add new site → Import an existing project → GitHub**를 선택하고 위 저장소를 고릅니다.
2. Build command는 비워 두고, Publish directory는 `.`으로 둡니다(`netlify.toml`에 이미 설정되어 있습니다).
3. **Deploy**를 누릅니다. 이후 깃허브에 수정 사항을 올리면 자동으로 다시 배포됩니다.

## 5단계: 동작 확인

1. 배포된 주소에 접속해 학번과 이름을 입력합니다.
2. 개념학습 1문항과 기출 1문항을 제출합니다.
3. 구글 시트 `기록` 탭에 두 줄이 추가되었는지 확인합니다.
   - 인터넷이 끊겨 전송하지 못한 기록은 브라우저에 보관했다가 다시 연결되면 자동으로 보냅니다.
   - 대기 중인 건수는 **내 기록** 화면에서 볼 수 있습니다.

## 문항 추가·수정

- **개념학습**: `data/concepts.js`의 각 문항은 아래 형식입니다.
  ```js
  {"book":"수학교육신론","ch":"4. …","sec":"4-4-1 오수벨과 유의미 수용학습","type":"설명",
   "q":"질문","kw":[["점진적","포괄"],["구체","분화"]],"a":"모범답안","id":"S101"}
  ```
  - `kw`는 **키워드 그룹의 목록**입니다. 한 그룹 안의 단어는 동의어라서 하나만 있어도 그 그룹은 충족됩니다.
  - 득점률은 충족한 그룹 수 ÷ 전체 그룹 수로 계산합니다.
  - `type:"용어"` 문항은 그룹이 하나이고, 인정할 답을 모두 넣습니다.
  - 띄어쓰기와 문장부호는 무시하고 비교합니다.
- **기출문제**: `data/exams.js`의 `parts`가 채점 요소(배점, 키워드 그룹)입니다.
  - `re:`로 시작하는 키워드는 정규식입니다. 순서 배열(예: 가-다-나-라-마)이나 수식을 확인할 때 씁니다.
- 새 연도 기출을 추가하려면 해당 문항 이미지를 `img/2027A01.png`처럼 저장하고 `exams.js`에 항목을 추가합니다.

## 검토가 필요한 모범답안

아래 문항은 교육과정 원문 문구나 평가원 정답과 대조가 필요해 앱 안에 따로 표시하지 않고 여기에 모았습니다. 확인 후 `data/exams.js`의 `model`과 `parts`를 고쳐 주세요.

| 문항 | 확인할 내용 |
|---|---|
| 2018 A1 | ㉡을 "내림차순·오름차순"으로 둠(2009 중학교 용어 → 2015 고등 학습 요소로 이동) |
| 2021 A8 | ㉠을 "근접발달영역"으로 두고 "비계설정"도 인정 |
| 2021 A9 | 교수·학습 방법을 "협력 학습"으로 두고 탐구·토의토론 학습도 인정 |
| 2022 B3 | ㉣ 정적분 도입 관련 교육과정 문구 |
| 2025 B3 | 브라운·월터 단계 명칭("What-if-not") |
| 2025 B5 | 평가 항목 ②의 교수·학습 방안 유형("탐구 학습") |
| 2026 B5 | ㉢ 성취기준·㉣ 성취기준 해설 문구 |

## 출처

- 기출문제: 한국교육과정평가원, 2016~2026학년도 중등학교교사 임용후보자 선정경쟁시험 제1차 수학 전공 A·B
  - 문항의 저작권은 한국교육과정평가원에 있습니다. 비영리 교육 목적으로 사용해 주세요.
- 개념학습 문항·모범답안·기출 모범답안: 두 교재의 목차와 수학교육론 일반 이론을 바탕으로 새로 작성한 것으로, 교재 문장을 옮긴 것이 아닙니다.
