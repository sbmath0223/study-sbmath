# 수학교육론 임용 대비 웹앱

중등 수학 임용을 준비하는 예비교사를 위한 수학교육론 학습 웹앱입니다. 메뉴는 **내용 정리 · 개념 퀴즈 · 기출문제 · 내 기록**입니다.

- **내용 정리**: 김민아 수학교육론 '키워드 빵꾸노트'의 목차(신론 20단원, 교재연구 & 성취기준 13단원)를 따라 단원별 핵심 내용을 정리했습니다.
  - 정리글은 이 앱을 위해 새로 작성한 것이며, 빵꾸노트의 문장을 옮긴 것이 아닙니다.
  - 2022 개정 교육과정 관련 10개 단원(신론 1~3, 교재연구 1·3·6·8·10·11·12)은 「2022 개정 수학과 교육과정」 고시 원문을 그대로 실었습니다.
    - 수식이 들어 있는 문단과 내용 체계 표는 고시 PDF에서 잘라 낸 이미지(`img/cur/`)로 보여 줍니다.
    - 신론 3의 "2015 개정 대비 주요 변화"만 원문을 대조해 앱에서 정리한 요약입니다.
- **개념 퀴즈**: 개념을 설명하는 문항(키워드 채점)과, 설명을 읽고 개념의 이름을 쓰는 문항(정확한 명칭일 때만 정답)으로 구성됩니다.
  - 단원을 다시 열면 안 푼 문항부터 이어서 풀고, 문항 번호를 눌러 원하는 문항으로 이동할 수 있습니다. '안 푼 문항', '70% 미만' 범위만 골라 풀 수도 있습니다.

- **기출문제 69문항**: 2016~2026학년도 중등 1차 전공 A·B의 수학교육론 문항(매년 24점)
  - 문항 원문 이미지를 보고 제한 시간 안에 답안을 작성합니다. 이론별·연도별로 볼 수 있고, 묶음 전체를 세트로 풀 수 있습니다.
  - '이론별 보기'는 빵꾸노트 목차(신론 20단원, 교재연구 & 성취기준 13단원) 순서로 묶었습니다. 여러 단원에 걸친 문항은 해당 단원마다 모두 들어 있습니다.
- **채점 방식**
  - **단답형(2점) 18문항**: 빈칸마다 답을 따로 입력하며, **정확한 명칭일 때만 정답**입니다. 띄어쓰기와 문장부호만 무시합니다(예: "분석"은 오답, "분석법"은 정답).
  - **서술형 51문항**: 필수 키워드(동의어 포함)가 들어 있는지로 채점하는 참고용 채점입니다. 모범답안과 해설을 함께 보여 줍니다.
- 제출한 답안과 점수는 학번·이름과 함께 구글 시트에 기록됩니다.

## 폴더 구성

```
index.html          웹앱 본체 (단일 페이지)
config.js           구글 앱스 스크립트 URL 설정
data/exams.js       기출 문항 정보·채점 요소·모범답안·해설
data/concepts.js    내용 정리(단원·소주제) + 개념 퀴즈 문항
img/                기출 문항 원문 이미지 (평가원 PDF에서 문항별로 잘라냄)
img/cur/            교육과정 원문 중 수식 문단·내용 체계 표 이미지
Code.gs             구글 앱스 스크립트 코드 (시트 기록용, 깃허브에 올려도 무방)
netlify.toml        넷리파이 배포 설정
```

## 1단계: 구글 시트와 앱스 스크립트

1. 구글 드라이브에서 새 스프레드시트를 만듭니다. 이름은 예를 들어 "수학교육론 학습 기록"으로 합니다.
2. 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 `Code.gs` 내용을 지우고, 이 폴더의 `Code.gs` 내용을 붙여 넣은 뒤 저장합니다.
4. 위쪽 함수 선택에서 **`setup`**을 고르고 **실행**합니다. 권한 승인 창이 뜨면 허용합니다.
   - 실행이 끝나면 시트에 `기록` 탭과 `학생별 요약` 탭이 생깁니다.
5. **배포 → 새 배포**를 누릅니다.
   - 유형 선택(톱니바퀴): **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
6. **배포**를 누르고, 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

> Code.gs를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영됩니다. 이렇게 하면 URL은 그대로 유지됩니다.

### 시트에 기록되는 항목

제출 시각, 학번, 이름, 모드(개념퀴즈/기출문제), 문항 ID, 구분, 단원/이론, 문항, 제출 답안, 점수, 만점, 득점률(%), 포함 키워드, 누락 키워드, 소요 시간(초), 제한 시간(초), 시간 초과

- 단답형은 "제출 답안"에 빈칸별 답이 `㉠: … / ㉡: …` 형태로, "누락 키워드"에 틀린 빈칸과 정답이 기록됩니다.
- `학생별 요약` 탭은 학번·이름·모드별 제출 수와 평균 득점률을 자동으로 집계합니다.

## 2단계: config.js 설정

`config.js`의 `GAS_URL`에 1단계에서 복사한 주소를 붙여 넣습니다.

```js
window.APP_CONFIG = {
  GAS_URL: "https://script.google.com/macros/s/여기에_복사한_ID/exec"
};
```

## 3단계: 깃허브에 올리기

1. 깃허브에서 새 저장소를 만듭니다. 예: `math-edu-imyong`
2. 이 폴더 안의 파일 전체를 저장소 최상위에 올립니다. 웹에서 **Add file → Upload files**로 폴더째 끌어다 놓아도 됩니다.

## 4단계: 넷리파이 배포

1. 넷리파이에서 **Add new site → Import an existing project → GitHub**를 선택하고 위 저장소를 고릅니다.
2. Build command는 비워 두고, Publish directory는 `.`으로 둡니다(`netlify.toml`에 이미 설정되어 있습니다).
3. **Deploy**를 누릅니다. 이후 깃허브에 수정 사항을 올리면 자동으로 다시 배포됩니다.

## 5단계: 동작 확인

1. 배포된 주소에 접속해 학번과 이름을 입력합니다.
2. 개념 퀴즈 1문항과 기출 1문항을 제출합니다.
3. 구글 시트 `기록` 탭에 두 줄이 추가되었는지 확인합니다.
   - 인터넷이 끊겨 전송하지 못한 기록은 브라우저에 보관했다가 다시 연결되면 자동으로 보냅니다.
   - 대기 중인 건수는 **내 기록** 화면에서 볼 수 있습니다.

## 내용 정리·개념 퀴즈 수정

`data/concepts.js`는 단원(`units`) 목록입니다. 단원마다 아래 두 가지가 들어 있습니다.

- `sections`: 내용 정리의 소주제입니다. `title`(제목)과 `body`(본문)로 되어 있습니다.
  - 본문에서 `- `로 시작하는 줄은 글머리 기호가 되고, `**굵게**`는 굵은 글씨가 됩니다.
  - 한 줄 전체가 `**제목**`이면 작은 소제목이 되고, `*기울임*`은 회색 작은 글씨(출처 표시 등)가 됩니다.
  - `![설명](img/cur/파일.png)` 한 줄은 이미지로 표시됩니다.
- `quiz`: 개념 퀴즈 문항입니다.
  - 개념 이름 쓰기(`"type":"용어"`): `accept`에 정답으로 인정할 명칭을 모두 넣습니다. 띄어쓰기·문장부호만 무시하고 정확히 같아야 정답입니다.
  - 개념 설명하기(`"type":"설명"`): `kw`에 키워드 그룹을 넣습니다. 한 그룹 안의 단어는 동의어입니다.
- 단원에 `"pending":true`를 넣으면 "준비 중"으로 표시되고 퀴즈에서 빠집니다. 현재는 33개 단원이 모두 공개되어 있습니다.

## 정답·채점 기준 수정

`data/exams.js`에서 문항 ID(예: `2026A01`)로 찾아 고칩니다.

- **단답형**(`"kind":"short"`): `blanks`의 `accept`가 정답으로 인정할 명칭 목록입니다. 띄어쓰기·문장부호만 무시하고 목록과 완전히 같아야 정답입니다.
  ```js
  {"label":"㉡","accept":["메타인지 이동","메타인지적 이동"],"mode":"name","pts":1}
  ```
  - `mode:"order"`는 (가)~(마) 배열 문항으로, 답에서 가·나·다·라·마만 뽑아 순서를 비교합니다.
  - `mode:"pair"`는 2025 B1처럼 "기호 + 고친 내용"을 쓰는 문항입니다.
- **단원 분류**: `units`에 빵꾸노트 단원 ID를 넣습니다(신론 `S01`~`S20`, 교재연구 `G01`~`G13`, 번호는 목차 번호). 예: `"units":["S18","S17","G02"]`
- **서술형**(`"kind":"essay"`): `parts`가 채점 요소입니다. `kw`는 키워드 그룹 목록이고, 한 그룹 안의 단어는 동의어입니다.
  - 득점은 충족한 그룹 수 ÷ 그룹 수 × 배점입니다. `re:`로 시작하는 키워드는 정규식입니다.

아래 문항은 교육과정 원문 문구나 평가원 정답과 대조가 필요합니다. 확인 후 `data/exams.js`의 `model`, `parts`(서술형) 또는 `blanks`(단답형)를 고쳐 주세요.

| 문항 | 확인할 내용 |
|---|---|
| 2018 A1 | ㉡을 "내림차순·오름차순"으로 둠(2009 중학교 용어 → 2015 고등 학습 요소로 이동) |
| 2021 A8 | ㉠을 "근접발달영역"으로 두고 "비계설정"도 인정 |
| 2021 A9 | 교수·학습 방법을 "협력 학습"으로 두고 탐구·토의토론 학습도 인정 |
| 2022 B3 | ㉣ 정적분 도입 관련 교육과정 문구 |
| 2025 B3 | 브라운·월터 단계 명칭("What-if-not") |
| 2025 B5 | 평가 항목 ②의 교수·학습 방안 유형("탐구 학습") |
| 2026 B5 | ㉢ 성취기준·㉣ 성취기준 해설 문구 |
